# Noiro Android TV

A free, open-source media app designed for Android TV and remote control navigation.

**Status: early development. This repository currently contains the project plan; no installable release is available yet.**

## First milestone

- A clear Home screen and media browsing
- Search
- Built-in video playback
- Subtitle selection
- Watchlist and Continue Watching

These are planned features. Development starts with a small, reliable foundation before expanding.

## Contributing

Use Issues for feature suggestions and discussion. Once test builds are available, include the device, Android version and steps to reproduce any problems. Discuss larger changes before starting a pull request.

Build instructions, licensing details and release downloads will be added before implementation is published.
